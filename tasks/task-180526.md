# Task 18/05/26

## Mục tiêu

Áp dụng rule để giám sát cơ bản việc học online bằng video:

1. Phải thực sự xem hết toàn bộ các video.
   - Chỉ khi giao diện xem video là giao diện được forceground mới phát video
   - Chặn tua nhanh: cho phép tua lại, xem lại phần đã học nhưng không cho phép nhảy đến các phần chưa học.

2. Đặt các bài kiểm tra cho mỗi bài học (video)
   - Buộc phải qua bài trước mới được xem bài sau (chỉ cần đặt giao diện chặn, không cần soạn nội dung ngay)
   - Sau khi hoàn thành tất cả các bài thì vào bài thi cuối khóa, xong bài thi mới coi là hoàn thành khóa học.

---

## Thiết kế hệ thống

### Loại bài học (`LessonType`)

Lesson thêm LessonType: CONTENT(bài học bình thường), QUIZ (bài kiểm tra), FINAL_EXAM (bài thi cuối khóa).

Suy nghĩ lại:

> Không cần `FINAL_EXAM` vì cấu trúc `course → chapter → lesson` cho phép tạo chapter cuối khóa và đặt quiz ở bất kỳ đâu.

### Cấu trúc ví dụ

```
Khóa học
├── Chương 1: Nhập môn
│   ├── Bài 1 (CONTENT — có video)
│   ├── Bài 2 (CONTENT — chỉ text)
│   └── Kiểm tra chương 1 (QUIZ)
├── Chương 2: Nâng cao
│   ├── Bài 3 (CONTENT — có video)
│   ├── Kiểm tra nhanh (QUIZ)
│   └── Bài 4 (CONTENT — có video)
└── Chương cuối: Tổng kết
    ├── Bài thi cuối khóa (QUIZ)
    └── Video lời chào (CONTENT)
```

### Bảng `LessonProgress`

Lưu tiến trình học của từng user. Khi user đạt điều kiện hoàn thành bài → ghi record vào bảng này.

---

## Quy tắc hoàn thành bài học

- Xem ≥ 90% thời lượng video (CONTENT có video)
- Tự động done khi vào bài (CONTENT không video)
- User bấm nút **DONE** (Tạm thời ấn done)

---

## Quy tắc mở khóa bài tiếp

- Bài đầu tiên luôn được mở
- Bài N chỉ mở khi bài N-1 đã hoàn thành
- Nếu user cố truy cập bài bị khóa → trả về lỗi, FE hiển thị trạng thái khóa và hướng về bài chưa hoàn thành

---

## Task:

### Backend (API)

- Thêm `LessonType` enum (`CONTENT`, `QUIZ`) vào Prisma schema
- Thêm bảng `LessonProgress` (userId, lessonId, createdAt)
- `GET /lessons/:id` — kiểm tra tất cả bài trước đó đã hoàn thành chưa, nếu chưa trả 404
- `POST /lessons/:id/complete` — ghi nhận hoàn thành bài học (upsert)
- `POST /manage-lessons` & `PUT /manage-lessons/:id` — hỗ trợ field `type`

### Frontend (FE)

- **ArtPlayer** — thêm `canSkip` prop, chặn tua vượt quá thời gian đã xem (chênh lệch 2s), tự động pause khi tab bị ẩn
- **Sidebar menu** — hiển thị trạng thái: đã hoàn thành / bị khóa / QUIZ badge; chặn click bài bị khóa + toast cảnh báo
- **CONTENT có video** — auto-complete khi xem ≥ 90%; nút "Bài tiếp" chỉ hiện sau khi hoàn thành
- **CONTENT không video** — auto-complete khi vào bài
- **QUIZ** — hiển thị layout riêng với nút **DONE**; bấm DONE → gọi API complete → cập nhật UI realtime
- **Bài bị khóa** — hiển thị màn hình thông báo + link về bài chưa hoàn thành

## Sửa component Artplayer

```ts
// Pause khi tab bị ẩn, resume khi quay lại
const handleVisibilityChange = () => {
  if (document.hidden) {
    wasPlayingBeforeHiddenRef.current = !art.video.paused
    art.pause()
  } else {
    if (wasPlayingBeforeHiddenRef.current) art.play()
  }
}
document.addEventListener('visibilitychange', handleVisibilityChange)

// Track thời gian xem xa nhất
art.on('video:timeupdate', () => {
  if (!canSkip) {
    const current = art.currentTime
    if (current > watchedTimeRef.current) {
      watchedTimeRef.current = current
    }
  }
})

// Chặn tua vượt quá thời gian đã xem (cho phép chênh lệch 2s)
art.on('video:seeking', () => {
  if (canSkip) return
  const current = art.currentTime
  const allowed = Math.max(watchedTimeRef.current, maxAllowedTime ?? 0)
  if (current <= allowed + 2) return
  art.currentTime = allowed
  art.pause()
  art.notice.show = 'Bạn không thể tua vượt quá thời gian đã xem'
})

art.on('destroy', () => {
  document.removeEventListener('visibilitychange', handleVisibilityChange)
})
```
